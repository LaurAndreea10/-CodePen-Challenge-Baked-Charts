# Sockspiracy — Baked Charts

An accessible, bilingual interactive data-visualization experiment created for the CodePen **Baked Charts** challenge.

[Live demo](https://laurandreea10.github.io/-CodePen-Challenge-Baked-Charts/) · [Portfolio](https://laurandreea10.github.io/codepen-portfolio/)

## Română

**Sockspiracy** transformă un grafic despre șosetele dispărute într-un mini-dashboard interactiv. Proiectul include română și engleză, mod luminos/întunecat și preferințe dedicate de accesibilitate.

### Funcționalități

- grafic donut SVG interactiv;
- perioade de 7 zile, 30 de zile și 12 luni;
- generare de seturi noi de date;
- legendă sincronizată cu graficul;
- navigare cu mouse, tastatură și touch;
- interfață RO/EN cu preferință salvată local;
- mod luminos și întunecat;
- contrast ridicat, text mărit și mișcare redusă;
- anunțuri pentru cititoarele de ecran;
- design responsive;
- metadate SEO, Open Graph și JSON-LD;
- sitemap și robots.txt.

## English

**Sockspiracy** turns a chart about missing socks into a playful interactive dashboard. It supports Romanian and English, light/dark themes, keyboard interaction and accessibility preferences.

### Accessibility

- semantic landmarks and headings;
- visible keyboard focus;
- minimum 44 px interactive targets;
- screen-reader live regions;
- high-contrast mode;
- large-text mode;
- manual and system reduced-motion support;
- persistent preferences using localStorage;
- descriptive SVG labels and no color-only information.

## Files

| File | Purpose |
| --- | --- |
| `index.html` | Semantic interface, metadata and structured data |
| `style.css` | Responsive design, themes and accessibility modes |
| `javascript` | Chart logic, localization and saved preferences |
| `pie.mmd` | Mermaid source for the baked chart |
| `prettier.json` | Formatting configuration |
| `robots.txt` | Crawler permissions |
| `sitemap.xml` | Public URL discovery |

## Keyboard controls

- **Tab / Shift + Tab** — move between controls;
- **Enter / Space** — activate a chart category or button;
- **Escape** — close the accessibility panel or clear a chart selection.

## Local use

Open `index.html` through a local HTTP server. No build step or framework is required.
