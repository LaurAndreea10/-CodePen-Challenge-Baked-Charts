# Changelog

All notable changes to **Sockspiracy** are documented here.

## 1.0.0 — 2026-09-16

### Added
- Romanian and English interfaces with persistent language preference.
- Separately indexable English page and reciprocal hreflang metadata.
- Light, dark, high-contrast, large-text and reduced-motion modes.
- Keyboard-accessible SVG chart with arrow navigation and live announcements.
- Editable data studio with exact 100% validation.
- Donut, pie and bar visualizations.
- CSV, JSON, SVG and PNG export.
- Native share or clipboard fallback.
- Local report history.
- Accessible tabular representation of all chart data.
- SEO metadata, JSON-LD, canonical URLs, sitemap and robots.txt.
- Responsive social preview, favicon and bilingual README.

### Fixed
- Corrected the dog involvement value from 1515% to 15%.
- Moved executable code to script.js to ensure a correct JavaScript MIME type.
- Removed duplicated inline JavaScript.
- Corrected invalid CSS keyframe syntax.
